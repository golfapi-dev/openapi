# GolfAPI.dev OpenAPI document

The OpenAPI 3 document for the GolfAPI.dev REST API: golf club specifications as each maker published them, from drivers to putters.

- Live document: [api.golfapi.dev/openapi.json](https://api.golfapi.dev/openapi.json). This copy follows it and is updated when the API version changes.
- Base URL: `https://api.golfapi.dev`. Every endpoint is a GET.
- Auth: `Authorization: Bearer sk_live_...` or `sk_test_...`. A free key is at [console.golfapi.dev](https://console.golfapi.dev/?plan=free&ref=github).
- Version: send `Golfapi-Version` or omit it for the current version.
- Docs: [golfapi.dev/docs](https://golfapi.dev/docs/?ref=github). Rate limits and plans: [golfapi.dev/pricing](https://golfapi.dev/pricing/?ref=github).

Import [`openapi.json`](openapi.json) into Postman, Insomnia or a client generator.
